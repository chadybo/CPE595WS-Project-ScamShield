## ScamShield

A web application to detect and advise users on potential phishing/scam attempts.

---

## Tech Stack

- Node.js & Express
- Handlebars(express-handlebars)

---

## Setup

### 1. Prereqs.

Make sure you have the following installed:

- Node.js v18 or higher

### 2. Clone the repo

```
git clone https://github.com/chadybo/CPE595WS-Project-ScamShield.git
```

### 3. Install Dependencies

```
npm install
```

### 4. Create a .env file

Create a file called `.env` in the project root and add the port

```env
PORT=3000
```

### 5. Start the app

```
npm start
```

Visit `http://localhost:3000` in your browser.
